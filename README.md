# SIC — Soluciones Integrales Caribe

Redesign of [sicsoluciones.com.co](https://sicsoluciones.com.co) for Soluciones Integrales
Caribe (Valledupar, Cesar): suministros y obras civiles, y sistemas de vidrio, aluminio y acero.

Rebuilt from the original WordPress site's content, structure, and imagery as a fast, modern
React application — same two business lines, same projects and brands, new front end.

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion for scroll reveals and page transitions
- React Router for client-side routing
- Phosphor Icons

## Pages

- `/` — Home
- `/nosotros` — About / company
- `/suministros-y-obras` — Suministros y Obras division
- `/vidrio-aluminio-acero` — Vidrio, Aluminio y Acero division, with project portfolio
- `/contacto` — Contact form (opens a pre-filled email; no backend)

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
